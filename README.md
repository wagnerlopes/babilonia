Resumo
------
Babilonia é uma API Rest Web Service, desenvolvido com Spring Boot 4, Spring Data e OpenApi. Foi desenvolvido com JDK 21 e focado em funcionalidades para consulta de unidades da fderação, mesorregiões, microrregiões, municípios, distritos e localidades do Brasil.

**Principais funcionalidades**

- Carregamento de planilha de dados de informações geográficas;
- Informações de unidades da federaçõa, macrorregiões, microrregiões, municípios, distritos e localidades;
- Localidades do Brasil com georeferencia;
- Distânica entre duas as localidades.

**Tecnologias**
- Java 21
- Spring Boot 4.x
- Spring Data (JPA)
- Open API 3.x
- Banco de dados (H2/PostgreSQL/MySQL — configurar conforme ambiente)
- Application Building com Apache Maven
